# The Refine page and the assistant in the Harness Console — evidence

> **Feature:** `HUB-075` (`features/features.yml`, ADR 0004 P2) · **Scenario:** `verify/scenarios/refine.yml` (the public build; not run this session) · **Result:** **PASS** by hand on a console (8 images, two viewports) · **Generated by:** Playwright MCP against the worktree's console on `127.0.0.1:4113` on 2026-11-04.

JEV capability three in the page (docs/HARNESS-REFINEMENT.md): Harnesses → **Refine** (`/refine`) shows the hub's harness surface as a sensor and the fleet sweep, one Propose–Probe–Compose plan per agent step with its ceiling against the month's `budget.loops`, the review queue of every unfiled loop-run preview with *Approve and file* behind the confirm gate, the evidence trees and the experience library with the $0 reflector's form; Operate → **Assist** (`/assist`) is the read-only assistant, one capped headless Claude Code session with the console's own MCP server attached.

## A running console (the interactive pass)

The console was started from the worktree (`uvicorn app:app` on `127.0.0.1:4113`, `CONSOLE_AUTO_HEALTH=0`, its own `DASH_CONSOLE_JOBS`, `JEV_RUNS_DIR` pointed at this machine's `.fleet/runs`, which holds one real local scout run from 2026-11-03 whose preview was never filed). For the sweep the worktree's empty `projects/` was pointed at this machine's submodule checkouts for the capture only (the worktree itself has none checked out), which is why the header's uncommitted count differs between images. Nothing was run that spends or writes: no `assist` question was asked, no preview was filed, every button pictured was left unpressed except *Read the preview*, *Show the schedule* and *New lesson*.
