# The generated repo app: every repo opens as an app — evidence

> **Feature:** `HUB-080` (phase F1 of [ADR 0005](../../../docs/adr/0005-console-as-fleet-portal.md)) · **Scenario:** `verify/scenarios/repo-app.yml` · **Result:** **PASS** (2/2 viewports, 24 steps each) · **Generated by:** `node verify/runner.mjs --only repo-app --base http://127.0.0.1:5113` against the public build (`CONSOLE_BASE=/ tools/console/build-pages.sh` into a scratch directory, served statically), 2026-11-05

A repo the shell has no frontend to frame opens as one generated app, at `/apps/<id>` and in a window on the Desktop. It is built from what the hub already holds about the repo, plus the repo's README where a console can read the checkout.

## The public build (the scenario)

Every step passed at both viewports: `/apps/?type=generated` listed the repos with no interface, each "opens as the generated repo app"; `/apps/kvlite/` answered 200 and showed the overview with its tiles, `git clone https://github.com/bamr87/kvlite` and no frame; the README tab said "The public page carries no README" and offered the repository; the Open work tab listed the repo's items; nothing scrolled sideways. No console errors were recorded.

## A running console (the interactive pass)

Driven with Playwright against a console started from this branch's worktree on `127.0.0.1:4012` (its own virtualenv and job directory; the shared core on `:4001` was not touched). The worktree has no submodules checked out, so `kvlite`'s real README was copied into `projects/kvlite/` for the pass and removed afterwards.

Measured in that pass, not pictured:

- **The README's links** resolved to the file's neighbours on GitHub (`PRD.md` to `https://github.com/bamr87/kvlite/blob/main/PRD.md`) and open in a new tab; the rendered document held no `<img>` and no `<script>`.
- **A repo not checked out** (`bashos`): the README tab said "not checked out on this machine" and offered the repository.
- **A repo owed a different component**: `bashos` says it is owed its terminal UI in a shell window, `zpl-viewer` a web preview; both open the same generated app meanwhile.
- **A repo with a frontend** (`gitorio`) still opens framed at `/apps/gitorio`.
- **The route** refuses a name that is not a registry project (404) and a path-shaped name (404 from the router, `ValueError` in the function).
