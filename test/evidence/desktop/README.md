# The bashOS desktop: an icon for every fleet app, each in a window — evidence

> **Feature:** `HUB-079` (phase D0 of [ADR 0005](../../../docs/adr/0005-console-as-fleet-portal.md)) · **Scenario:** `verify/scenarios/desktop.yml` · **Result:** **PASS** (2/2 viewports, 23 steps each) · **Generated by:** `node verify/runner.mjs --only desktop --base http://127.0.0.1:5113` against the public build (`CONSOLE_BASE=/ tools/console/build-pages.sh` into a scratch directory, served statically), 2026-11-05

The console's **Desktop** page is the bashOS OS shell in the browser. Its window state is bashOS's own layout reducer (vendored byte-identical, pinned by `tools/console/test_bashos_shell.py`), every window hosts the common App Shell around a framed fleet app, and the Fleet window lists every repo by the frontend component it has or is owed.

## The public build (the scenario)

Every step passed at both viewports: `/desktop` answered 200 with the title `Desktop · bashOS` and an icon per app; the page had fetched nothing from another origin and held no frame (`off_site_requests: 0`); the **Fleet** icon opened the list of every repo in its four groups; `kvlite` opened as the generated repo app in a window; nothing scrolled sideways. No console errors were recorded.

Measured in that pass, not pictured:

- **Open and focus.** A click on an open app's icon raises its window instead of opening a second; shift-click opens a second one.
- **Move, snap, resize.** A title-bar drag moved the window; released on the right edge it filled the right half of the window area, on the left edge the left half; the corner handle resized 778×517 to 678×457.
- **Minimize and restore.** The window was hidden with its frame kept loaded; its taskbar button brought it back focused.
- **The dock stays reachable.** With a window maximized and with four tiled, every icon could still be clicked; the window area starts where the dock ends (186 px at 1440×900, 272 px at 1280×720, no icon clipped).
- **The layout.** A reload restored the tab's windows. A crafted `?windows=` link naming a URL where an id goes, an app the registry does not have, an unknown scene and twenty windows opened six windows, all of registry apps, framing only `it-journey.dev`; a garbage parameter fell back to Welcome.

## What the pass found

1. **New windows opened on top of the second icon column**, so those icons could not be clicked until the window was moved. Fixed: the icons are a dock beside the window area, not a layer under it.
2. **The dock pushed the window area off-screen**: a grid that flows in columns sized itself as one row of eighteen icons. Fixed: the page counts the rows that fit and the columns that takes.
3. **The phone header truncated to "basl"** beside two pills. Fixed: the connection pill is dropped at a phone's width.
