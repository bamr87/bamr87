# The Stars page renders the radar, the starred list, trending, fleet matches, AI themes, the map and a repo drawer — evidence

> **Feature:** `HUB-NEW:stargazer` · **Scenario:** `verify/scenarios/stars.yml` · **Result:** **PASS**, desktop and mobile · **Generated by:** `node verify/runner.mjs --only stars` against the public build of the worktree (`CONSOLE_BASE=/ tools/console/build-pages.sh`, served on `http://127.0.0.1:4071`) on 2026-11-23, plus a hand-run capture of the Grafana dashboard.

The page reads the committed `_data/stars.json`, which is public data, so the replayable scenario checks the **public build** in full: every tab, the drawer and no sideways scroll at phone width. Its assertions name sections, never counts or repos, because the data changes daily. The data was read from GitHub the same day (`tools/dash stars refresh`: 139 stars, 3 public lists, 44 fleet repos, 8 trending searches, 44 discovery searches; 20 GraphQL calls). The AI layer came from two real, capped `tools/dash stars review --yes` runs: 24 repos reviewed in two sessions ($0.19) and the stars grouped into 10 themes in one ($0.14), all API-equivalent (estimate), each recorded in the AI ledger. The first review session ended `agent_error` with no answer ($0.08); that is why a failed batch is now retried once as two halves.

## How the Grafana image was made

The running Grafana mounts the main checkout's dashboards, so the dashboard was checked in a throwaway container instead: `docker run --rm --pull never --network fleet -p 127.0.0.1:3091:3000` with the worktree's `provisioning/` and `dashboards/` mounted read-only, reading the stack's own Prometheus through the pinned `fleet-prometheus` datasource. It was stopped and removed afterwards; nothing in the running stack changed except the pushed `fleet_stars_*` series.

**One defect found while capturing it, fixed in the same change:** the collector test ran a full `refresh`, which pushes metrics by default, and with no endpoint configured it pushed the fixture radar into the live collector. Its rows (`new/actions-reviewer`, `jane/jekyll-docs-theme`, `old/jekyll-relic`) are visible in *Closest to the fleet* in this image. `tools/test_stargazer.py` now points every push at a dead port. Prometheus runs without its admin API, so the fixture series could not be deleted; they leave the tables' two-day window on 2026-11-25, and the shared series (totals, categories, languages) were overwritten by the next real push.
