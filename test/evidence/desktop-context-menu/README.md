# An icon and a title bar have a context menu, and one action puts Live beside Local, which a reload and a layout link keep — evidence

> **Feature:** `HUB-079` · **Scenario:** `verify/scenarios/desktop-context-menu.yml` · **Generated by:** `node verify/runner.mjs --only desktop-context-menu` against the static build (`CONSOLE_BASE=/ tools/console/build-pages.sh`, served on `http://127.0.0.1:4071`) on 2026-11-16

Right-click an app's icon, or press Shift+F10 on it, for open, open beside, Live beside Local, a new tab and a link. Live beside Local opens two windows, each filling a half, one on each target. A window's title bar offers the same, by right-click or its button, and Escape closes a menu without leaving the desktop. A reload of the tab, and the taskbar's layout link opened on its own, bring both windows back on their own targets (#701); a link naming a target, a device or a path the registry does not declare opens the app's default instead. Desktop widths only: a phone has one app at a time.
