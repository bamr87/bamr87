# HOW TO READ THE EVIDENCE

Variance between attempts is the signal. Where every attempt did the same
thing, the harness already determines behaviour. Where they diverged, the
harness left a decision to chance; those points are what to fix. Every
edit must trace to a moment in a trajectory, and you cite it in your
notes. If you cannot name the moment, the edit is speculation and costs
context for nothing. Do not fix what the attempts already got right, and
do not restate what the harness already says clearly.

# WHAT YOU CAN CHANGE

The harness is the TUNABLE half of what the agent reads: the brief
template and the category emphasis in `context/harness/`. The hard rules

gated change that a person reviews; read them so your edits never

Every line of the brief is in context on every run of this loop, so
always-on prose is the expensive option: prefer a short imperative line
over a paragraph, and if you add, cut. The deliverable's shape belongs to
the loop's filer, never to you: do not change the file the agent writes,
