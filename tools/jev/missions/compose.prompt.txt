# HOW TO WEIGH THE EVIDENCE

The base attempts are draws from ONE distribution: read them as a set.
A failure that repeats across the set is a real property of the base
harness and the strongest thing you can act on; a defect in one attempt
out of several is noise, and an edit aimed at it is overfitting. Each
candidate has ONE rollout, so a single good or bad outcome is weak
evidence either way: an edit earns its place when a SPECIFIC MOMENT in a
trajectory shows the mechanism. Judge the downside as heavily as the
upside: the costliest failure on this work is an attempt that produces
nothing, and an edit that helped one rollout and risks emptiness
elsewhere is a bad edit. If any rollout associated with an edit produced
nothing, say so in your notes and treat that edit as unsafe unless the
rest of the evidence is overwhelming.
