# SCHEMA — fleet

> Generated configuration for the shared container plane: what the hub's Postgres provisions for the rest of the fleet.

## Conventions

- **Nothing here is hand-authored.** Everything is rendered from `_data/projects.yml` + `_data/fleet.yml` `containers:` by `dash gen compose`. Edit the registry, regenerate, commit both.
- Committed on purpose, unlike the per-project overrides in `.fleet/compose/`: this is mounted into the Postgres container at startup, so it has to exist in a fresh clone before anything has been generated.

## Structure

| entry | kind | purpose | rules |
|---|---|---|---|
| `SCHEMA.md` | file | This contract | required |
| `db-init/` | dir | Postgres entrypoint scripts — one database + role per project declaring `database: true`. Mounted read-only at `/docker-entrypoint-initdb.d`; also piped through `psql` by `dash up` so a data volume that predates a project catches up | generated |

## Placement

- New shared-service bootstrap (a Redis ACL file, a seed script) → its own subdirectory here, generated by `fleet_compose.py` and mounted read-only by `docker-compose.yml`
- Anything unrouted → propose an entry in this table first, then create it.

## Forbidden

- No hand-edits: `dash gen compose --check` fails on the diff and the next generate discards them.
- No credentials. The dev password comes from `FLEET_DB_PASSWORD` in the environment, with a throwaway default; this tree is public.
