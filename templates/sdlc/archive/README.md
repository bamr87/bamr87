# archive/

Byte-exact snapshots of kit files as they shipped in earlier versions, named `<file>-<version>.<ext>`. `tools/fanout.sh --upgrade` refreshes a target's copy only when it matches the current kit or one of these, so hand-modified copies are never overwritten. Snapshot a file here BEFORE changing it. Snapshots: `docs-README.template-0.1.0.md` and `docs-adr-README-0.1.0.md` (the 0.1.0 docs index and ADR index).
