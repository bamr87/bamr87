# Documentation Index

Every document in `docs/`, plus the guides at the repository root. The root [`README.md`](../README.md) is a GitHub profile; start with [DEVELOPMENT.md](DEVELOPMENT.md) to work in the repo, [`SCHEMA.md`](../SCHEMA.md) for where things live, and [`CATALOG.md`](../CATALOG.md) for everything the hub provides. When you add, rename or remove a doc, update its row here in the same change (a new doc is `UPPERCASE-TOPIC.md`, per [SCHEMA.md](SCHEMA.md)).
