## 📁 This repository

Besides being my profile, this repo is the **control plane** for the portfolio: a monorepo that mounts about 40 of the projects above as Git submodules under `projects/`, plus the shared standards, CI, dashboards and AI harnesses that keep them consistent. The dash is live at [bamr87.github.io/bamr87](https://bamr87.github.io/bamr87/).

```
bamr87/
├── projects/    # the fleet: one Git submodule per project
├── _data/       # registries: projects.yml (the fleet), portfolio.yml (this index), profile.yml
├── specs/       # the Universal Project Standard (REPOSITORY, QUALITY, WORK, ...)
├── templates/   # kits fanned out to every repo (CI, schema, community files, ...)
├── tools/       # dash, drift gate, fan-out and conformance tooling
├── .github/     # workflows, dash-gen and the shared CI gate
└── docs/        # monorepo documentation
```

## 🚀 Quick start

Clone with all submodules:

> [!TIP]
> Use `--recurse-submodules` on the first clone to avoid missing nested project dependencies.

```bash
git clone --recurse-submodules https://github.com/bamr87/bamr87.git
cd bamr87
./tools/setup.sh
```
