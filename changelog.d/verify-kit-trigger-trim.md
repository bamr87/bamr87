### Changed

- `templates/verify/` 0.2.0: the seeded `verify.yml` caller of `fleet-verify.yml` stops re-running a verdict it already has. A label other than `verify` now gets a concurrency group of its own and a skipped job, so it neither re-runs the pass nor cancels the run in flight (Dependabot's two labels started 3 runs per PR, the content agents' four started 5). The `push:` trigger is gone: 151 of 155 sampled pushes to a default branch were merges of a PR that had just been verified, and a dispatch still verifies the default branch. Every PR commit and the `verify` label run as before, and `gate` is unchanged. Over 14 days these runs were 469 of the fleet's 1,009 Verify runs and 946 of its 2,840 wall-clock minutes. `archive/` keeps the 0.1.0 shapes, so `tools/fanout.sh --kit verify --upgrade` moves the 23 untouched copies.
