### Added

- The loop runner's context pack: before each local attempt the host reads the fleet's planes (the data lake, the code index, Claude Code telemetry) and the loop's own earlier attempts and places one capped, redacted, freshness-stamped `context.md` beside the brief in the clone, with a pointer in the clone's copy of the brief; the sealed agent only reads a file and the reviewed prompt bytes are unchanged. A step spec's `local.context` block (`mode`, `file`, `providers`, `max_chars`, `deadline_s`, `days`) sets it; `tools/dash loop plan|run --context auto|off|require` overrides it (`off` is the CI-identical attempt, `require` fails an item whose plane is down before any spend), `loop run --refresh-context` imports this machine's Claude Code sessions into the lake first, `loop plan` previews each item's planes and `loop doctor` shows the hub's ([docs/JEV.md](docs/JEV.md#the-context-pack), #561).
