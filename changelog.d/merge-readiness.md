### Added

- `pr-review.yml`: merge readiness (ADR 0012), off unless the calling repo's `vars.PR_READINESS_ENABLED` is `true`. With it on, the one PR comment also lists what is left before the pull request merges (checks, base, draft state, the review gate and its label, the governance trace, the task list, review threads), stays while anything is left, and gives way to one `COMMENT` review per head commit when nothing is. In the hub the workflow also runs on the pull-request events that start no workflow (`pull_request_target`: opened, reopened, marked ready, converted to a draft, pushed to, labelled, unlabelled, edited); a stub gains that trigger with kit 0.3.0. The reusable workflow's inputs, jobs' permissions and behaviour with the variable unset are unchanged, and its sparse checkout of the hub now includes `tools/` and `_data/`.
